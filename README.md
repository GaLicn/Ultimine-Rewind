
# Ultimine Rewind

为 FTB Ultimine 添加最近一次连锁采集的撤销功能。玩家可以按 `Ctrl+Z` 打开恢复界面，并使用对应方块作为恢复材料。

| 项目 | 版本 |
|---|---|
| Minecraft | 26.1.2 |
| NeoForge | 26.1.2.97 |
| FTB Ultimine | 26.1.2.5 |
| Java | 25 |

## 构建

```powershell
.\gradlew.bat build
```

构建产物位于 `build/libs/`。
